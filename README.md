# Iris Flower Classification Using Machine Learning

## 1. Introduction
This project uses Machine Learning to classify Iris flowers into three different species based on their physical measurements.

The three species are:
- Setosa
- Versicolor
- Virginica

## 2. Objective
The main objective is to build a classification model that predicts the species of an Iris flower using its sepal and petal measurements.

## 3. Dataset
The project uses the Iris dataset from Scikit-learn.

Dataset details:
- Total records: 150
- Features: 4
- Target classes: 3

Features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## 4. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 5. Machine Learning Algorithm
The project uses a classification algorithm to predict the flower species based on the input measurements.

## 6. Model Results
- Training records: 120
- Testing records: 30
- Model Accuracy: 93.33%

## 7. Visualizations
The project generates:
- Confusion Matrix
- Iris Flower Species Visualization

- iris_classification.py

## 9. Conclusion
The Iris Flower Classification project demonstrates how Machine Learning can be used to classify flower species based on their measurements. The model achieved an accuracy of 93.33%, showing good classification performance.
